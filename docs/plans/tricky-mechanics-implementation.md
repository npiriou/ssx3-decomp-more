## Native object integration findings for the next work

These are implementation leads, not completed object mechanics.

- `custom_resolve_resource.rs` retains the inspected 0x3a8cd0 port uninstalled. That entry inserts a resource; do not call it for lookup. Resident type-3 lookup: app=`*(0x4a28a8)`, module=`*(app+84)`, world=`*(module+10)`, cache=`*world`, banks=`*(cache+8)`, bank=`banks[section]`, refs=`*(bank+1c)`, count=`*(bank+20)`, word=`refs[index]`, pointer=`(word>>8)<<2`. Require a live low-byte reference count and reject the empty sentinel gp+16e0. A miss waits for residence.
- `custom_anim_object_factory.rs` retains the exact native AnimObject factory 0x2fbcb8. It takes sret Vec3 A0, count A1, 16-byte named args A2. Param 0 is an instance RID or -1 for the script's current instance. It attaches modifier type 1 to an existing node, otherwise allocates 0x6c and invokes `AnimObject_ctor(new,1,1,Instance*,params)`. Eleven parameters: types `[int,int,int,float,float,float,float,float,int,int,int]`. The constructor still needs study before mapping source modes to it.
- The actual native MDR relocation callback is 0x3abe40 (already typed in `game/world/worldview.rs`). Its following virtual slot +0x30/+0x34 relocates nested model data; inspect that existing typed pipeline before copying curve payloads. The live resolver vtable observed was 0x495090. Tricky part animation data is currently discarded: native MDR part-table word +8 is written as zero by `ssx3_models.py`.
- Source PBD curve header is BasePosition vec3, BaseRotation vec3, action/channel mask, channel count, offsets-start, then per-channel pointers. Each channel has count/offset followed by cubic coefficient quartets and start/end time. SSX3's WorldMDR reader exposes the analogous third-pointer block but does not fully interpret it; do not assume relocation conventions are identical.
- `WorldObj_BuildMatrices` already has a typed body in `game/object/instancenode.rs` but is not in that unit's override list. `WorldObj_ctor` is 0x34fb00; instance+0xc links its dynamic node. Native animations/modifiers should update both rendering and collision through this structure.
- Do not trust the old structs document's description of instance flag bit 1 as simply dead: `cPS2ChunkResolve_v13` initializes instance flags with `|2`. Study real hide/dead-node operations before mutating flags.
- A typed, uninstalled contact dispatcher is in `custom_object_trigger.rs`: rider interface is based at Rider+6c0, contact-A+50 holds Instance*, instance+78 is its compact RID. Existing typed `rider_states::rider_update_progress` is another possible contact-hook point; preserve native pickup/sign dispatch.
- `custom_race_time_limit.rs` and `custom_draw_race_time.rs` retain inspected ports uninstalled. Neither owns the Slopestyle time budget; it is app->eventEntity (+c0), deadline +78 and enable +88. AI+0c is elapsed race ticks. These fields were confirmed by the existing typed `Rider_CheckRaceFinish` and native snapshots.

### Curve codec and native object scripts after the solo checkpoint

- `tricky_models._object_animation` decodes source part animation descriptors and their exact cubic tracks. `ssx3_models._pack_animation` emits the native third-pointer data. Tricky's model duration is **frames30**, while its curve key times and SSX 3 MDR+14 duration are **seconds**: divide only the header duration by 30. Curves/coefficients remain exact. Native Mesa/Elysium/Pipedream openings observed; no sampled approximations or renderer changes.
- Native relocation has now been followed through existing typed bodies: MDR callback 0x3abe40 -> virtual +30/+34 = **0x3aa438** (part table); part+8 -> virtual +58/+5c = **0x3aa830** (animation descriptor); that uses virtual +60/+64 = **0x3aa8d8** (channel header). All offsets are relative to MDR base: descriptor+20 points to channel pointer table, descriptor+1c is channel count, each channel+4 points to its curve array. Source PBD offsets are relative to its animation/channel descriptors, so the serializer repacks them.
- Source extraction through the new reader succeeded on Tokyo (31 animated parts/40 channels), Aloha (29/35), Mesa (31/36), Elysium (20/25). Other maps/native consumption remain to inspect.
- `custom_anim_object_ctor.rs` retains the exact 0x341aa0 port uninstalled. Native params: +4 mode (1 loop,2 pingpong,other clamp); +8 direction (1 reverse); +c/+10 explicit bounds in frames30, negative bounds use native defaults; +14 frames/sec; +18 variation; +1c initial frame (negative starts at lower bound); +20 random start; +24 force dynamic ownership. Set lower bound explicitly to 0 for a full known cycle, rather than assuming default GetDuration is zero. The actual WorldObj subobject is ctor allocation+30 and Instance is at +48. This node supplies native render/collision matrices and process registration.
- `custom_rider_place.rs` retains the exact 0x11d660 port uninstalled for the teleport work. A3 is an animation ID, **not flags**. F12 is ground clearance: negative preserves the exact supplied position, nonnegative performs a vertical ground query and adds clearance. It resets motion/impulses/contacts, camera (when view valid) and vibrations, but does not select Ground/Air, prime AirPredictor or rewrite track pointers/cursors. It preserves elapsed race timestamps. Use native state/velocity helpers afterwards and resynchronize the TrackPath/cursor to avoid awarding skipped checkpoint sweeps. An exact exit candidate is Rider_Place(rider,exitPos,exitFacing,5,-1), followed by source exit motion/state handling; do not claim that as fully decided or verified yet.

## Native object script wave (in progress)

- `ssx3_luno.calls_blob` emits existing literal/native-call/return instructions and ordinary function descriptors. It interns functions in the same world script table as the unchanged retail pickup/sign scripts. Source effect persistent channel 0 becomes native focus-entry slot **1**, contact channel 1 becomes native slot **2**. Indirect instance/function links retain explicit target RIDs. The translator currently stops at Wait/Gate rather than treating their tails as unconditional; full scheduling/conditions remain work.
- An early TAN1 host-update prototype was removed. Native `FocusLeave` intentionally kills an AnimObject without a slot-3 leave script; `FocusEnter` recreates it through slot 1. Native focus lifetime, matrix evaluation, Nash updates and collision queries own the resulting actors. No custom animation renderer or transform sampler is installed.
- Native builtin IDs 3/4/5 create AnimObject/Delta/Combo. Message builtin 28 receives 0x8c for source delta command 2 and 0x82 for source combo command 3. Native Debounce builtin 1 takes seconds and its contact callback is a no-op until expiry. Omitting it initially let Elysium's delta budget accumulate to 126 seconds; preserving the source 1-second debounce keeps the budgets bounded.
- Object curve commands on genuinely static prefabs are skipped (e.g. several named Tokyo fan/door models have no curve and duration zero). Names are not evidence of motion, and no invented spin is added.
- Native MeshAnim builtin 13 maps the authored frame step, duration, launch ranges, throw vector and contact scale to the existing SSX 3 constructor. Remaining angular settings use SSX 3 defaults. The source model's complete hierarchy/geometry is kept; inspection of every referenced source MeshAnim found no model above the native 24-part capacity. Hard-hide source mode 4 explicitly maps to native DeadNode mode 0; other source dead modes are not conflated.
- `custom_script_effects` supplies unused Luno builtins 111..114 for native reset, matrix placement, path selection and path projection. **WScriptMan[0] is a signed rider index**, resolved through AI+28, not a Rider pointer; player index zero is valid. Reset invokes native `Rider_ForceReset` from the real collision script context. A native reset state also clears the host volume sweep so the respawn cannot cross distant lift/lap volumes.
- Teleport placement uses native `Rider_PlaceAtMatrix` with a temporary frame: source local +Y becomes native placement +X, and the source six-slot spread is applied at 300 cm. The native helper performs state/FX/camera/ground placement. Two following native calls select and project the destination race path; both rider distance fields are primed and the old event count cleared. Host volume sweep is invalidated, but awarded SOP groups/lap progress stay intact. This still needs a real portal traversal.
