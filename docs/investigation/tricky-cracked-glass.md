## Native integration (v40)

- `custom_cracked_glass` retains strength, source lifetime and the half-second contact gate only. The initial contact uses the recovered VU0 four-lane dot/FPU sequence and exact0x3d1374bd multiplier. Subsequent contacts use the same arithmetic only after the gate, without replacing health or the material. Positive lifetimes retain Tricky's truncated frames60 duration at the configured game rate.
- Builtin124 returns whether native ownership needs creation. The compiled graph uses the existing VM false-branch instruction to skip Object0/TexFlip22/registration125 for a live pane. Native TexFlip has initial frame1 and speed0. Its own table contains private material records; no shared material or texture is mutated. Native Init0x35f218 was translated and retained uninstalled with no override entries or tests. Its fixed capacity is eight materials; conversion rejects larger models or source flipbooks outside this supplied two-frame family. No random frame selection is invented.
- Native Object/TexFlip identities protect against focus cleanup/replacement; restart/course changes clear retained state. Native WorldObj_KillRestorable(node,1) runs at the script-manager epilogue after process iteration when strength or lifetime expires. Its existing end dispatch executes the imported graph, with null rider/contacts through the existing detached scope. It owns pane/support removal and fragment creation. A completed record is marked before that native call, so a yield cannot dispatch it twice.
- `.cache/tricky-cracked-v40-inspection.json` inventories the actual final Race/Freestyle BAMs:20 contact functions each invoke124,0,22,125; their native false branch skips the latter three calls.
